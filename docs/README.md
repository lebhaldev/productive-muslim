# Nurday — specification set

Nurday is a calm, local-first Android app: one sourced ayah, one sourced hadith, a quote, habits with streaks, mood, activity log and a daily journal.

These documents are the source of truth for building the app. They follow the **design** (Claude Design file `Nurday.dc.html`) wherever the design and the original brief disagree. Anything the design does not show yet is listed as an open question, not invented.

| File | What it defines |
|---|---|
| [01-functional-spec.md](01-functional-spec.md) | Screens, behaviour, functional rules (FR-x) and content rules |
| [02-technical-spec.md](02-technical-spec.md) | Stack, architecture, data model, APIs, technical rules (TR-x) |
| [03-design-system.md](03-design-system.md) | Colours, type, components as seen in the design |
| [04-dev-plan.md](04-dev-plan.md) | Phases, definition of done, testing and Play release steps |
| [05-design-sync.md](05-design-sync.md) | How specs stay in sync with design, sync log, open questions |
| `design/` | Dated design snapshots the specs were synced against |
